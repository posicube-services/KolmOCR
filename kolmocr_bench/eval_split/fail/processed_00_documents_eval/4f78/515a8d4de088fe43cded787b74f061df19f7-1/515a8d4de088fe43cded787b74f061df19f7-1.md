# BioMate MBC2881 and MBC781 Membrane System

## BioMate MBC2881

<!-- bbox: [104,551,208,563] -->
<!-- bbox: [104,345,208,357] -->
<!-- bbox: [104,139,208,150] -->
### Description

<!-- bbox: [129,368,853,414] -->
<!-- bbox: [129,162,867,208] -->
- Purpose: EPA-registered biocidal balanced system for RO systems and membrane fouling.
- Application: Can be used in various types of systems by feeding the raw water supply to the upstream process.
- Operation Time: Typically 30 minutes.

<!-- bbox: [104,425,182,436] -->
<!-- bbox: [104,219,182,230] -->
### Features

<!-- bbox: [154,448,875,515] -->
<!-- bbox: [154,242,875,309] -->
- Effectiveness: Effectively inhibits bacterial growth and biofouling.
- Compatibility: Can be used with Kleen* MCT antifouling agents for enhanced performance.
- Biocide: Contains polyamide films, polyvinylidene fluoride (PVDF) membranes, and other materials that are biologically stable.
- Performance: Enhances the performance of RO systems by reducing biofouling and improving system lifespan.

## BioMate MBC781

### Description

- Purpose: EPA-registered biocidal balanced system for RO systems and membrane fouling.
- Application: Feeds the raw water supply directly to the system.
- Compatibility: Can be used with GE Water & Process Technologies' cleaning programs for enhanced performance.

### Features

- Effectiveness: Effectively inhibits bacterial growth and biofouling.
- Compatibility: Works well with Kleen* MCT antifouling agents for enhanced performance.
- Biocide: Contains polyamide films, polyvinylidene fluoride (PVDF) membranes, and other materials that are biologically stable.
- Performance: Enhances the performance of RO systems by reducing biofouling and improving system lifespan.
